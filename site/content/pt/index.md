O CallingSupportApp é um aplicativo **open source e gratuito** que ajuda os líderes de uma ala ou ramo a organizar atividades —a Viagem ao Templo, os acampamentos, as aulas de EnglishConnect, a autossuficiência— com inscrições, vagas, listas e avisos, cuidando dos dados dos membros. Ele é desenvolvido pela **CSATeam**, uma equipe de colaboradores voluntários.

> **Não é um site oficial** de A Igreja de Jesus Cristo dos Santos dos Últimos Dias; as informações oficiais estão em [churchofjesuschrist.org](https://www.churchofjesuschrist.org). **Não substitui as Ferramentas para Membros (Member Tools)**, o aplicativo oficial: apenas acrescenta funcionalidades que hoje não existem.

Todo o projeto é regido pelo [Manual Geral](https://www.churchofjesuschrist.org/study/manual/general-handbook?lang=por). Se uma ideia o contradizer, ela não será construída.

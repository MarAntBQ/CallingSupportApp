# Código de conducta

CallingSupportApp lo hace CSATeam, un equipo de colaboradores iguales. Esperamos respeto, bondad, honestidad, decisiones escritas y públicas, cuidado de los datos de las personas y paciencia con quienes colaboran como voluntarios.

No aceptamos acoso, insultos, burlas, discriminación, publicación de datos personales ni el uso del proyecto para promocionarse, hacer negocio o hacer política.

Si ocurre un problema, quienes mantienen el repositorio pueden ocultar comentarios, cerrar conversaciones o bloquear el acceso, explicando el motivo. Para reportar una conducta, usa el [formulario de contacto del sitio](https://callingsupportapp.org/contact/). Consulta la [versión completa del código de conducta](https://callingsupportapp.org/conduct/).

Este archivo resume la norma del sitio; la versión completa es la referencia.
